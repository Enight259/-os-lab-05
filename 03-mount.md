Вопрос 1:
/tmp это единственная директория кроме домашней в которую может писать любой пользователь. Из за noexec ядро запрещает выполнение любых файлов из этого раздела.
~~~

~~~
Вопрос 2:
nosuid - запрещает работу SUID, который позволяет обычному пользователю запускать программу с правами root. Даже если пользователь создаст в /tmp файл с таким битом, система его просто не выполнит.
nodev - не позволяет создавать в этой файловой системе специальные файлы устройств. Такие файлы могут быть использованы для обхода изоляции или получения низкоуровневого доступа к системы.
~~~
